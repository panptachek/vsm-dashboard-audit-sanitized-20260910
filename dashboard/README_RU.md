# Обезличенная копия VSM Dashboard

Это копия исходного кода для независимого технического аудита. Реальные строки
БД, учетные данные, `.env`, ключи, токены, журналы, выгрузки, резервные копии,
загруженные пользователями документы и production-конфигурация исключены.

## Состав

- `api/` - FastAPI и тесты без локальных виртуальных окружений и артефактов.
- `frontend/` - React/Vite, статические SVG и Playwright-сценарии.
- `docker-compose.audit.yml` - изолированный локальный контур.
- `../database/schema.sql` - схема PostgreSQL без данных, владельцев и ACL.
- `../database/seed_synthetic.sql` - только синтетические данные.
- `../database/vsm_synthetic.dump` - проверенный custom-format dump.

Бинарные производственные шаблоны отчетов и внешние генераторы не включены,
поскольку они могут содержать метаданные или реальные справочники. Для аудита
доступны соответствующий код и текстовые контракты.

## Локальный запуск

1. Создайте `.env` на основе `.env.example`.
2. Замените все значения `REPLACE_*` случайными локальными значениями.
3. Запустите:

```bash
docker compose --env-file .env -f docker-compose.audit.yml up --build
```

Интерфейс будет доступен на `http://127.0.0.1:18083`, API - на
`http://127.0.0.1:18090`. Почтовые интеграции работают только в dry-run режиме.

Для повторной инициализации удалите только volume этого audit-compose проекта и
запустите его заново. Не подключайте этот пакет к production-БД.

## Отдельное восстановление дампа

```bash
createdb vsm_synthetic
pg_restore --no-owner --no-privileges --dbname=vsm_synthetic ../database/vsm_synthetic.dump
```

Все доменные идентификаторы имеют префикс `DEMO` либо фиксированные UUID,
а синтетические примечания помечены `SYNTHETIC DATA`.
